# ![Zephyr Client](https://github.com/user-attachments/assets/caab0e5a-0160-4011-b51e-e10b9168277b)
A Minecraft Classic Protocol & Classic Protocol Extension compatible client written entirely in Java.

## What is Zephyr?
Zephyr is a client for the Minecraft Classic Protocol, The protocol that runs all ClassiCube and early Minecraft Servers. Zephyr also has full support for the Classic Protocol Extension, An extension to the MCP that adds hacks, building tools and various other client/server features.
